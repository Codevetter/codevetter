# Why

CodeVetter's public site explains review and publishes a narrow synthetic benchmark, but it does not yet teach the product's current execution-backed verification category. Search and agent readers need a coherent path from the category definition to workflow, evidence, comparison, and proof.

# What changes

- Add four evidence-first public guides for coding-agent verification.
- Reframe `/benchmark` as the proof hub without changing recorded results or hiding limitations.
- Add canonical metadata, structured data, sitemap coverage, agent-readable Markdown, and contextual internal links.
- Reuse the existing landing-page visual language and preserve current navigation, analytics, privacy copy, and benchmark data.

# Out of scope

- New verification runtime behavior, benchmark runs, model claims, dependencies, deployment policy, or production release automation.

# Impact

The Astro marketing surface gains new static routes and a small shared reading layout. The desktop application and verification runtime are unchanged.
