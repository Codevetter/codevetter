## REMOVED Requirements

### Requirement: Provider execution remains internal to Work

**Reason**: Work is discontinued as a primary product surface because CodeVetter will not compete with official coding-agent clients.

**Migration**: Existing provider history and backend data remain intact during the compatibility period; users run coding agents externally and bring their changes to Review, Testing, or Performance.

### Requirement: Terminal management is not a primary mode

**Reason**: Removing the Work route makes a hidden terminal-management mode unnecessary as a product contract.

**Migration**: No alternate terminal mode replaces Work inside CodeVetter.
