## Current objective

Make CodeVetter the local-first primary workbench for one connected workflow:
Usage, Repo Unpack, Work, Board, Review, and Testing. Functionality and visual
quality must ship together. Usage remains the finished default surface, Work is
the current product priority, Board is the orchestration layer across the
workflow, and Repo Unpack remains the deepest intelligence investment.

## Blockers

- **External benchmark claims remain unauthorized** — the 20 real agent-PR
  cases have exact external capture blockers for the three comparator slots;
  the production CodeVetter pipeline and adjudication pass has not run over
  that corpus.
- **Archaeology scale claim remains unsupported** — the current full-repository
  run fails closed at the persisted linker input bound. The checked evidence
  does not qualify 18M lines or 100,000 rules.
