# CodeVetter pricing and availability

CodeVetter currently charges no subscription, account, licence, or hosted-service fee.

## Available without purchase

- The Apple-silicon macOS build is published through GitHub Releases.
- The source, benchmark cases, scorer, product documentation, and release workflows are public under the ISC licence.
- The packaged CLI and read-only stdio MCP sidecar run locally as part of the desktop distribution.

## Costs outside CodeVetter

Optional provider-backed review uses the LLM provider or authenticated CLI that
the user configures. Any provider subscription, token charge, quota, or account
policy belongs to that external provider; CodeVetter does not resell those
services or process the payment.

## Not currently offered

There is no CodeVetter checkout, paid API, hosted verification service, team
subscription, credit pack, Homebrew cask, or separately published npm package.

Current product availability: https://codevetter.com/download
