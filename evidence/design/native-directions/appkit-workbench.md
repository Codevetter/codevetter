# Direction: AppKit-led Evidence Workbench

AppKit owns the application lifecycle, multi-window behavior, menus, toolbars,
split views, source outlines, dense tables, keyboard routing, and focus. SwiftUI
composes bounded forms, evidence panels, settings, inspectors, and transitions.
Rust remains the capability, execution, persistence, and receipt authority.

Selected because CodeVetter is a dense professional Mac instrument and because
this direction preserves access to the full native desktop surface without
moving verification policy into Swift.
