# Native Review and Explore qualification

Local implementation for [#285](https://github.com/Codevetter/codevetter/issues/285).
No commit, push, release, or production installation was performed.

## Implemented workflow

- GitHub repository, PR, commit (including abbreviated SHA), branch, and file URL import.
- Partial Git fetch, immutable commit/blob identities, initial source before background indexing.
- Native file tree, fuzzy quick-open, indexed literal search, JS/TS declaration navigation,
  labelled identifier-reference candidates, source history and blame.
- Unified/split diffs, expandable context, base/head and full-source switching.
- AppKit viewport drawing/highlighting over bounded Rust source windows.
- Source-linked Unpack, modules, repository instructions, architecture/decision documents,
  dependencies, recorded findings, and runtime stack locations.
- Automatic deterministic Unpack after imported text indexing; imported snapshots preserve
  HEAD and explicitly report source exclusions.
- Local diff drift rejection and stale native request suppression.

## Continuation, 2026-09-14

- Bundled Microsoft's native TypeScript 7.0.2 binary and standard declarations, pinned through
  the `navigator-typescript` pnpm alias. This is a production runtime asset, not a Node runtime
  or a user-managed language-server requirement. Apache-2.0 license/notice are copied with it.
- Rust owns bounded stdio LSP framing, UTF-16 positions, per-session/per-side workers, and
  position caches. Only definition/reference requests are exposed; server-initiated requests
  are refused. Requests time out after 30 seconds; workers are stopped on disposal/failure.
- Workers receive separate bounded immutable snapshots containing JS/TS and admitted compiler
  configuration. Path aliases work. No package installation, project execution or plugin
  loading is performed. The macOS sandbox denies outside reads, file writes and network.
  Imported dependency packages and external config references remain unavailable.
- Added real-server tests for cross-file aliases, compiler path aliases, typed properties,
  shadowed parameters, Unicode positions, reference isolation, immutable local bytes and
  separate base/head source. Framing rejects oversized, malformed and truncated responses.
  Sandbox tests deny outside-file reads, writes, and even localhost network connections.
- Repaired accessibility values on keyboard movement, diff row movement/copying, UTF-16
  source positions, context-menu symbol selection, and stale repository session disposal.
  Removed the container identifier that overrode child control identifiers.
- Background checks: 100 Swift tests passed; five focused navigator tests passed after final
  native changes, including actual Swift-to-Rust-to-LSP navigation. Native Debug build and
  deep signature verification passed. Rust Clippy, 18 native script tests, lint, Knip,
  changed-file complexity and docs validation passed.
- All 14 Rust tests passed against the binary actually embedded in the Debug app; two live
  network tests remained ignored in this continuation. The packaged-server fixture measured
  163 ms cold and 9.7 microseconds warm mean (the development-path run was 33 ms cold).
  A 100,000-line offscreen viewport test measured approximately
  11 ms p95 across 100 samples. These are fixture/renderer measurements, not display timing
  or repository-wide end-to-end guarantees.
- `pnpm quality:dependencies` is **red**: pre-existing `knip -> smol-toml@1.6.1`,
  [GHSA-7w5x-hrqm-74c2](https://github.com/advisories/GHSA-7w5x-hrqm-74c2). The same vulnerable
  version exists in the committed lockfile; the new compiler dependency did not introduce it.
- No foreground automation was performed in this continuation. New semantic interactions,
  full VoiceOver, and display-frame measurements still require fresh idle-screen authorization
  or a dedicated graphical runner. Nothing was committed, pushed, deployed, or released.
