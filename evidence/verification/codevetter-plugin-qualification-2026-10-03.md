# CodeVetter local plugin qualification

The owner requested one CodeVetter plugin around the review, testing,
performance and value-evaluation workflows. This records local source,
package, installation and protocol evidence; it does not establish agent
productivity or public availability. Tracking: [#348](https://github.com/Codevetter/codevetter/issues/348).

## Package and install

- Plugin identity: `codevetter@codevetter-local`, version `0.1.0`.
- Four implicitly selectable skills retain their canonical source bytes.
- Eighteen explicitly allowlisted runtime files, with SHA-256 inventory.
- Python stdio MCP provides discovery, planning, filtered history, surgical
  receipt inspection and append-only usefulness assessment.
- No added production dependencies, execution hook, arbitrary command tool,
  provider invocation, foreground automation, public publication or native
  app release.
- Codex marketplace listing recognized the package; `codex plugin add`
  returned its installed cache path. A subsequent plugin listing reported
  `installed: true` and `enabled: true`.
- All eighteen installed file hashes matched the package receipt.
- A relocated package boots using its manifest-declared command, independently
  of the checkout. Its relative Markdown resource links resolve inside the
  package; public canonical documentation uses HTTPS links.

The task-private package and host smoke responses are retained under
`artifacts/codevetter-plugin-2026-10-03-ready/`. The invocation ledger remains
in the existing private CodeVetter application-data directory. Sources were
locally modified/uncommitted during qualification; this is not an exact
published-source qualification.

## Meaningful contract checks

Seven package/bridge tests pass: relocation, source parity, non-overwrite,
symlink refusal, protocol discovery, recorded discovery, negative assessment,
failed launch retention, filtered pagination, pointer access, receipt tamper
rejection, closed input schemas, bounded planning and target containment.
Some tests exercise multiple related contracts.

The thirty-six existing recorder/telemetry/assessment tests and two standalone
installer tests pass. Targeted Biome checks, strict Knip and canonical docs
validation pass. Knip retains an existing non-failing `codevetter`
ignore-binary configuration hint. No native or browser execution was needed
for this tooling-only change.
