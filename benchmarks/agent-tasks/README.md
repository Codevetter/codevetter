# Agent-task corpus

The machine contracts, validator, provider-neutral runner, and 30-task owned
corpus support the coding-agent evaluation work tracked in
[issue #53](https://github.com/Codevetter/codevetter/issues/53).

Read
[`docs/development/agent-task-corpus.md`](../../docs/development/agent-task-corpus.md)
before adding or changing task artifacts. The corpus passes its strict contract
publication gates with 30/30 qualified tasks across eight categories. That
qualification proves reproducible task definitions, baseline failures,
known-good outcomes, and cleanup; it is not evidence that any real agent or
context provider performs better.
