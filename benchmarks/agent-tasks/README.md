# Agent-task corpus

The machine contracts, validator, and intentionally unqualified sample support
the realistic coding-agent corpus tracked in
[issue #53](https://github.com/Codevetter/codevetter/issues/53).

Read
[`docs/development/agent-task-corpus.md`](../../docs/development/agent-task-corpus.md)
before adding or changing task artifacts. The sample proves only the immutable
contract and fail-closed readiness behavior; it is not publishable benchmark
evidence.
